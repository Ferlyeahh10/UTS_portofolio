Tentang Saya

Latar Belakang

Saya Ferlya Tabitha, seorang pengembang yang memiliki pengalaman 1 tahun dalam pembuatan website. Saya sangat tertarik pada pengembangan front-end dan fokus pada penggunaan teknologi dasar, yaitu **HTML5 dan CSS3**. Saya memiliki kemampuan untuk menerjemahkan desain visual menjadi kode fungsional yang responsif.

Saya percaya bahwa dasar yang kuat dalam HTML dan CSS adalah kunci untuk membangun pondasi web yang kokoh dan mudah dikelola, sebelum beralih ke bahasa pemrograman atau *framework* yang lebih kompleks.

Keahlian

  • HTML5 (Struktur Semantik)
  • CSS3 (Layout Flexbox & Grid, Responsif)
  • Pengujian dan Debugging Dasar
  • Desain Antarmuka Pengguna (UI/UX Dasar)
  • Git dan GitHub (Kontrol Versi Dasar)
